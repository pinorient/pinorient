pinorient

A pure Go / SQLite geocoder built on PocketBase and OpenStreetMap data.

Pinorient translates written addresses into map coordinates using OpenStreetMap data stored locally in SQLite with FTS5 full-text search. It is a lightweight, self-hosted alternative to the Photon API — no Java, no Elasticsearch, no Docker orchestration. One static binary, one SQLite database.

GitHub Hosted Service

Features

  • Forward geocoding (/api/geocoder/search?q=...)
  • Autocomplete (/api/geocoder/autocomplete?q=...)
  • Reverse geocoding (/api/geocoder/reverse?lat=...&lon=...)
  • Bounding-box filtering and result limits (/api/geocoder/autocomplete?q=12+Englewood+Ave&bbox=-73.5,41.3,-72.8,41.6&limit=5)
  • Ranked partial matching across multiple features
  • US address interpolation via TIGER/Line data
  • Wildcard domain restrictions
  • Photon-style class/type and importance scoring
  • Periodic OSM data refresh via cron
  • Tuned to run a full US import on a 2 GB VPS

Quick start

git clone https://github.com/pinorient/pinorient
cd pinorient
make run   # builds and starts the server; OSM data downloads automatically

Starts the server and indexes OpenStreetMap data in the background (initial startup downloads and indexes several GB of data and may takes several minutes to complete). See the README for configuration options and API documentation.

API example

curl "http://localhost:8090/api/geocoder/search?q=Bowdoin%20College&limit=3"
